# Code of Conduct

## Our commitment

Portugal Safe Emergency Validator is committed to maintaining an open, respectful, and collaborative environment for all contributors.

## Expected behavior

Contributors should:

- communicate respectfully;
- provide constructive feedback;
- focus on technical improvements;
- respect security and privacy requirements;
- help maintain reliable emergency data practices.

## Unacceptable behavior

The following is not acceptable:

- harassment or discrimination;
- publishing private information;
- introducing secrets or credentials;
- intentionally introducing unsafe changes;
- misleading claims about project capabilities.

## Security concerns

Security vulnerabilities should not be reported through public issues.

Please follow the instructions in SECURITY.md for responsible disclosure.

## Scope

This code of conduct applies to all project interactions, including issues, pull requests, and discussions.
