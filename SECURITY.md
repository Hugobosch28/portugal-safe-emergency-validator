# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, please do not disclose it publicly through GitHub Issues.

Report security concerns privately with:

- a description of the issue;
- steps to reproduce the problem;
- potential impact;
- any relevant technical details.

## Security principles

This project follows these principles:

- no secrets or credentials stored in the repository;
- validation logic is separated from private application infrastructure;
- changes should preserve existing security controls;
- security issues should be handled responsibly.

## Scope

This repository contains validation tooling for emergency and public-safety data records.

It does not contain:

- private user data;
- production credentials;
- emergency communication infrastructure;
- operational secrets.
